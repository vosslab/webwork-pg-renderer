# Renderer fonts

The renderer self-hosts the variable WOFF2 files required by
[`docs/FONT_STYLE.md`](../../docs/FONT_STYLE.md).

- `AtkinsonHyperlegibleNext-Variable.woff2` and
  `AtkinsonHyperlegibleNext-Italic-Variable.woff2` come from
  `googlefonts/atkinson-hyperlegible-next` revision
  `7925f50f649b3813257faf2f4c0b381011f434f1`.
- `AtkinsonHyperlegibleMono-Variable.woff2` comes from
  `googlefonts/atkinson-hyperlegible-next-mono` revision
  `154d50362016cc3e873eb21d242cd0772384c8f9`.

Each family is distributed under the SIL Open Font License 1.1. The matching
license text is stored beside its font files.
